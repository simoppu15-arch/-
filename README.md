# 近镜 OBS

**用 iPhone 当无线直播摄像头，保留 OBS 自己的虚拟摄像头。** 手机连 Wi-Fi，在 Safari 扫码，近镜把画面送进 OBS 的「浏览器」来源。这样 OBS 仍能启动虚拟摄像头，把你排好的直播画面交给抖音直播伴侣等支持虚拟摄像头的软件。iPhone 无需安装 App。

同一路手机画面可以用于不同平台的直播。你可以用 OBS 自己推流，也可以用 **OBS Virtual Camera** 把 OBS 场景交给各平台客户端。如果要同时向多个平台推流，需在 OBS 或平台端另行配置推流。近镜负责把手机画面送到 OBS。

## 下载

在 [v1.0.3 的下载页](https://github.com/simoppu15-arch/-/releases/tag/v1.0.3) 找到 [[**NearCam-OBS-Setup.exe**](https://github.com/simoppu15-arch/-/releases/download/v1.0.3/NearCam-OBS-Setup.exe)](https://github.com/simoppu15-arch/-/releases/download/v1.0.3/NearCam-OBS-Setup.exe)，下载后双击安装，约 222 MB。电脑需要 64 位 Windows 10 或 11、Edge 或 Chrome，以及 OBS Studio。安装需要管理员权限，默认安装到 D 盘，完成后桌面会出现「近镜 OBS」。

## 第一次连接

1. 手机和电脑接入同一个 Wi-Fi。电脑接到同一路由器的网线也可以。
2. 打开桌面的「近镜 OBS」，用 iPhone 相机扫「首次连接」二维码，在 Safari 按提示安装并信任这台电脑的连接证书，然后点「开始传输」。以后扫「以后直接连接」即可。换电脑时需要重新设置。
3. 在电脑的近镜窗口点「复制 OBS 直播源地址」。在 OBS 的「来源」点 **＋ → 浏览器**，把地址粘贴到「URL」。用这个接法时，让近镜的「兼容输出」保持关闭，OBS 就可以使用自己的虚拟摄像头。
4. 让手机方向、OBS 浏览器源和 OBS 画布一致。竖拍时填 **1080 × 1920**，横拍时填 **1920 × 1080**。到 OBS「设置 → 视频」，把基础画布和输出分辨率都设成同样大小。
5. OBS 有画面后，点「启动虚拟摄像头」。在直播伴侣里选 **OBS Virtual Camera**，分辨率跟 OBS 一致，帧率建议先用 **30 FPS**。麦克风在直播软件里另外选。

## 常见问题

- **扫码打不开**：先确认 iPhone 和电脑接在同一个网络。访客 Wi-Fi 或公司网络可能禁止设备互相访问。
- **连接过一会儿就断**：让 Safari 保持前台，手机别锁屏。回到页面后可以再点一次「开始传输」。
- **OBS 里有黑边**：把手机转到想直播的方向，再检查 OBS 浏览器源的宽高和画布是否一致。选中来源后可按 `Ctrl+F` 适配画布。
- **OBS 启动虚拟摄像头失败**：回近镜点「停止兼容输出」，再回 OBS 启动虚拟摄像头。这个直播接法需要用 OBS 的「浏览器」来源接画面。
- **直播伴侣画面糊**：先看近镜显示的实际接收分辨率，再看 OBS 浏览器源宽高和直播伴侣摄像头选中的分辨率。简单放大两倍补不回原有细节。
- **Windows 出现未知发布者提示**：此版安装包未做商用代码签名。下载后可用 Release 附带的 SHA-256 文件检查完整性。

画面在手机和电脑所在的局域网传输。近镜不会主动录像，也不会把画面上传云端。当前版本使用 Wi-Fi，USB 连接暂未实现。不再使用时，可在安装目录运行「卸载近镜.exe」，并到 iPhone「设置 → 通用 → VPN 与设备管理」移除对应的连接证书。

## 第三方组件

安装包内含未修改的 OBS Studio 32.2.2 组件和 Node.js 24.16.0。各组件的许可文本随安装包提供。OBS 的对应源码和构建文件见 [OBS Studio 32.2.2 源码](https://github.com/obsproject/obs-studio/tree/32.2.2)，Node.js 的源码见 [Node.js v24.16.0](https://github.com/nodejs/node/tree/v24.16.0)。安装包也包含使用的 GPUPixel 源码及其许可。
